32 businesses compiled from the official DEQ Radon Service Providers GIS. DEQ publishes this as a mitigation-oriented convenience list of nationally certified providers (not a state license roster). Retrieved 2026-09-03 (US/Pacific).

If you are not sure you need a pro yet, see when a DIY radon test kit is enough or how to test a home for radon.

Montana does not issue a state radon license. DEQ does not certify these contractors and has no jurisdiction over their conduct. Names, cities, certification labels (NRPP / NRSB / AARST), and websites are transcribed from the public Montana Radon Service Providers FeatureServer table hosted by DEQ. The map is titled mitigation service providers, so rows are marked mitigation here; measurement capability is not published as a separate field. County coverage counts come from the same DEQ table (providers may list many counties). Credential shows the DEQ reg_cert value when published, otherwise unknown.

Always verify the credential is still current with NRPP or NRSB, and check the Montana DEQ Radon Control Program, before hiring. This index does not rank contractors or take referral fees.
